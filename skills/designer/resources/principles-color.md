# 色彩理论 · L1 学科原理

> **学科共识，非项目特定**：本文是通用色彩学科的原理与可执行规则，不针对任何单一品牌或项目。若与项目 specific design token 冲突，以项目 DESIGN.md / token 为准；本文提供的是"为什么"与"可执行阈值"。

---

## 〇、一句话总纲

所有颜色设计决策，最终都落到三个可量化维度上：**色相（是什么色）**、**饱和度（多鲜艳）**、**明度（多亮）**；而可用性则落到一个硬指标——**对比度**。颜色是主观的，但对比度是数学的。

---

## 一、色彩基础

### 1.1 色彩三要素（HSB / HSV）

| 维度 | 英文 | 含义 | 取值 | 调整后感知 |
|------|------|------|------|-----------|
| 色相 | Hue (H) | 颜色在色环上的位置 | 0–360° | 换"色"，如红→蓝 |
| 饱和度 | Saturation (S) | 颜色的纯度/鲜艳度 | 0–100% | 0%=灰，100%=最鲜 |
| 明度 | Brightness/Value (B/V) | 颜色的亮暗 | 0–100% | 0%=黑，100%=白 |

**可执行记忆点**：
- 调"颜色倾向" → 改 H；调"鲜艳/稳重" → 改 S；调"深浅/层次" → 改 B。
- 做**层次渐层**时优先动 **B（明度）**，次要动 S——人眼对明度变化比饱和度变化敏感得多。
- 做**柔和/莫兰迪**风格 → 大幅降 S（如降到 20–40%）并略调 B，别去大改 H，否则会"换色"。

### 1.2 RGB vs HSL（两种模型，不要混用）

| 模型 | 用途 | 组成 | 特点 |
|------|------|------|------|
| RGB | 屏幕/物理像素输出 | 红、绿、蓝 0–255（或 0–100%） | 机器语言，人类难以直觉调整 |
| HSB/HSL | 人类创作/调色 | 色相、饱和度、明度（HSL 里 L≈明度） | 人类直觉，按"什么色+多鲜+多亮"思考 |

**可执行记忆点**：
- **创作/调色阶段用 HSB**（设计师、给颜色做细微调整），**落库/交付/输出用 RGB/HEX**。
- 想"把蓝色调得更柔和" → 用 HSB 降 S；直接用 RGB 手工调三个值几乎做不到。
- 绝大多数设计工具（Figma/Photoshop）颜色面板同时给出 HEX、RGB、HSB，**默认看着 HSB 操作**。

### 1.3 加色 vs 减色（两种色彩系统）

| 系统 | 场景 | 三原色 | 混合规则 |
|------|------|--------|----------|
| **加色 RGB** | 发光体：屏幕、显示器、LED | 红绿蓝 (R,G,B) | 叠加越亮 → 越接近白；全 255=白 |
| **减色 CMY** | 反射体：印刷油墨、纸张 | 青、品红、黄 (C,M,Y,+K) | 叠加越暗 → 越接近黑；K=黑色油墨 |

**可执行记忆点**：
- 屏幕/数码只关心 **RGB 加色**。
- 做**印刷物料**（名片、海报）必须转 **CMYK**——RGB 里很鲜艳的亮蓝/亮绿，印刷后常明显变暗、变灰。交付印刷前要在设计工具里"预览 CMYK"（通常叫 Print Preview / 色彩管理）。
- 纯黑印刷建议用 **#000000* 而非 0,0,0**——实际印刷会加 K 通道，避免用"纯 RGB 黑"导致印出来偏灰发闷（也可直接用彩色黑）。

## 二、色彩心理学（推测性，非绝对）

> ⚠️ **重要警告**：以下所有"颜色=情绪"的映射都是**经验性、文化相关、推测性**的通用倾向，**不是**普适定律。受众文化、行业、个人经历都会改写结论。**绝不可仅凭一条倾向做产品决策**，必须配合对比度、色盲、语义冗余一起验证。

| 颜色 | 通用倾向 | 推荐场景 | 慎用/注意 |
|------|----------|----------|-----------|
| **红** | 紧迫、警告、危险、冲动、促销 | 报错、危险操作、限时折扣按钮 | 别大面积铺红（易焦虑）；别只用红表示"成功" |
| **蓝** | 信任、稳定、专业、科技、冷静 | 金融机构、企业官网、科技产品主色 | 大面积冷蓝可能显得疏离 |
| **绿** | 成功、安全、环保、通过 | 成功态、完成提示、环保/健康品牌 | 注意：绿也是"可以/通过"，但与"报错红"混用易歧义 |
| **黄** | 警告、注意、活力 | 警告条、注意提示、橙色系促销 | 亮黄配白底对比度极差（见第五节），别做正文/按钮文字色 |
| **橙** | 能量、行动、温暖 | 行动号召 CTA、促销、非正式品牌 | 与"警示黄"语义接近，别同时用在两处 |
| **紫** | 尊贵、奢华、创意、神秘 | 高端品牌、创新/抽象概念 | 阶调多变，跨设备色差大，居中才稳 |
| **黑/白/灰** | 中性、正式、极简 | 文字、背景、留白、层级 | 灰色是万能中性，但别把正文灰到对比度不够 |

**可执行记忆点（三条硬规则）**：
1. **颜色永远不单独承担语义**——同一语义必须同时用**文字/图标**表达（报错用红色+⚠️图标，而非只飘红）。
2. **按"受众与场景"校准**——同一种蓝，银行是"信任"，游戏是"科技冷感"；先确认受众再定色。
3. **颜色是增强项，不是决策项**——功能靠布局+文字+层级，颜色只做情绪与引导的放大器。

## 三、配色方案类型（带有示例）

> 色环上的相对位置（间隔角度）决定配色类型。H = 色相。以下示例 H、S、B 均为示意值。

### 3.1 单色（Monochromatic）—— 安全、高级
- **结构**：同一色相 H 不变，只改变 S/B。
- **规则**：取一个基准 H，生成 5 档 B（如 10/30/50/70/90），S 可小幅动。
- **示例**：深蓝 #1E3A5F、蓝 #2E5B8A、亮蓝 #4E86B5、浅蓝 #9BB8D4、白蓝 #E8F0F8。
- **何时用**：需要统一、克制、信任感（金融、医疗、企业后台）。**最低风险**，几乎不会丑。

### 3.2 类比（Analogous / Similar）—— 和谐、自然
- **结构**：色环相邻的 2–4 个色，间隔约 30°–60°。
- **规则**：相邻色间隔别超过 60°，主色占大头，两个辅色做点缀。
- **示例**：青绿（H 160）+ 绿（H 140）+ 黄绿（H 120）；或 蓝+靛蓝+蓝紫。
- **何时用**：自然、清新、科技、柔和界面。比单色更生动但依旧和谐。

### 3.3 互补（Complementary）—— 强对比、抓眼
- **结构**：色环正对面两色，相隔 180°。
- **规则**：一眼望去最刺眼的组合，**必须区分主次**（一主一辅，面积比建议 7:3 或 8:2）。
- **示例**：红（H 0）+ 青绿（H 180）；蓝（H 220）+ 橙（H 40）。
- **何时用**：CTA 与背景、强调边缘、海报。**警惕**：大面积等量的两个互补色会视觉"抖动"、难读。

### 3.4 三角（Triadic）—— 活力、平衡
- **结构**：色环三等分，三色各隔 120°。
- **规则**：三色最好**一主二辅**，且至少一色降饱和度/明度，否则三色打架。
- **示例**：红（H 0）+ 黄（H 120）+ 蓝（H 240）。
- **何时用**：儿童、游戏、多彩品牌。**危险**是抢戏，务必压低辅色。

### 3.5 分裂互补（Split-Complementary）—— 高级、不刺眼
- **结构**：取一色 + 它的互补色**两侧的两个相邻色**（各隔约 150° 与 210°）。
- **规则**：比纯互补更柔和、更有层次，主色+两个邻近暖/冷辅色。
- **示例**：主蓝（H 220）+ 目标 选黄红（H 40）与 黄绿（H 100）两侧。
- **何时用**：需要互补的兴奋感、但又不想太刺眼的界面——**很多高端品牌主色调**。比互补更稳。

### 3.6 中性加强调（Neutral + Accent）—— 现代、最实用
- **结构**：大片黑/白/灰（中性）+ 少量 1 个强调色（Accent，占约 10%）。
- **规则**：强调色通常只用一处（CTA、链接、选中态），中性色承担 90% 面积。
- **示例**：#12181F 背景 / #E5E8EB 文字 / #FF6B35 强调（橙色按钮）。
- **何时用**：**现代 SaaS、仪表盘、数据产品默认首选**——最耐看、最克制、最不难看，且天然容易做对比度达标。

## 四、WCAG 对比度计算与等级

> 这是**全文唯一的硬性数学标准**，务必照做。

### 4.1 对比度公式（WCAG 2.x，C 代表 Contrast Ratio）

C = (L1 + 0.05) / (L2 + 0.05)

- **L 是相对亮度**，L 越大越亮；L1 = 较亮者，L2 = 较暗者。所以 C 永远 ≥ 1，最大 21（纯白#FFF vs 纯黑#000）。
- 相对亮度 L 计算：
  - 先对 RGB 归一化（0–1）：R' = R/255, G'=G/255, B'=B/255
  - 线性化：每个通道若 ≤ 0.03928 则除以 12.92；否则 `((c+0.055)/1.055)^2.4`
  - `L = 0.2126*Rlin + 0.7152*Glin + 0.0722*Blin`

**可执行捷径**：不用手算，直接用在线计算器（如 WebAIM Contrast Checker）或设计工具内置对比度检查。**唯一要记住的数字见表 4.2。**

### 4.2 对比度等级阈值（记住这 3 个数字）

| 等级 | 用途 | 最小对比度 | 判定 |
|------|------|-----------|------|
| **AA（正文）** | 常规正文文字 | **4.5 : 1** | 达标 |
| **AA（大文本）** | 大号文字（≥18pt 或 ≥14pt 粗体）| **3.0 : 1** | 达标 |
| **AAA（正文）** | 更高无障碍要求 | **7.0 : 1** | 优秀 |
| **AAA（大文本）** | 大号文字 | **4.5 : 1** | 优秀 |
| **非文本 UI 组件** | 图标、控件边界、输入框 | **3.0 : 1** | 达标 |

**文本背景对比度标准（默认执行）**：
- **正文**：正文字色 vs 背景色 **≥ 4.5:1**。
- **大标题**：≥ 3:1（但建议仍做到 4.5:1 更稳）。
- **非文本可交互元素**（图标、按钮描边、焦点框、勾选态）：≥ 3:1。
- 若做品牌主按钮，**文字色与按钮底色比对≥4.5:1**，同时按钮底与背景**看起来区分即可**（非文本可 3:1）。

### 4.3 如何选"安全的文字色"（三步可执行）

1. **先用高对比**：正文/按钮文字**默认用"深底浅字"或"浅底深字"**，即文字与底色取对比度 ≥ 4.5:1 的组合。黑底白字（21:1）或白底深灰（如 #1A1A1A，约 18:1）几乎永远安全。
2. **避免中低明度撞色**：别用"中灰字 + 中彩底"（如 #777 字在 #AFAFAF 底，或黄色字在白底），这几类对比度常掉到 2–3:1，不达标且难读。
3. **实测验证**：任何主文字色都过一遍计算器，**正文字色 ≥4.5:1，大标题 ≥3:1**；低于阈值就加深文字（降 B）或变浅背景（升 B）。

**常见安全/危险速查**（白底 #FFF 下的文字色对比度）：
| 文字色 | 对比度 | 判定 |
|--------|--------|------|
| #000000 | 21.0 | ✅ AAA |
| #1A1A1A | ~18 | ✅ AAA |
| #333333 | ~12.6 | ✅ AAA |
| #595959 | ~7.0 | ✅ AAA |
| #767676 | ~4.5 | ✅ AA 正文临界 |
| #999999 | ~2.8 | ❌ 不达标（仅可用于禁用态） |
| #B0B0B0 | ~2.0 | ❌ 禁用态 |

## 五、色盲友好设计（可执行规则）

### 5.1 背景：红绿色盲最常见
- 红-绿视觉感知（Protanopia / Deuteranopia，常称"红绿色盲"）是最常见类型，男性约 8%，女性约 0.5%，**占总人口约 4–5%**。
- 这类用户**很难区分红色与绿色**，尤其当两者明度/饱和度相近时。蓝-黄色盲少见得多。

### 5.2 硬规则：不要只靠颜色区分信息（可执行检查清单）
1. **颜色永远 + 文本/图标**：状态必须文字化或图标化。例：
   - 成功：绿色 ✅ + 文案"已通过"
   - 报错：红色 ⚠️ + 文案"失败"
   - 进行中：蓝色 ⏳ + "处理中"
   三个状态即使都配色，也不会因色盲误读。
2. **不要只靠红/绿做对错**——用 ✅/❌、✓/✕、↑/↓、开/关 等符号补足。
3. **图表**：色盲友好的对比组合参考——
   - ✅ 蓝 + 橙、蓝 + 黄、橘红 + 蓝紫、亮青 + 暗红
   - ❌ 红 + 绿、深红 + 深绿、粉红 + 浅绿（几乎必踩红绿色盲）
   - 同一张图**尽量切换色相，别只改饱和度/明度**（红绿两个不同饱和度的"同明度"色，色盲眼里几乎一样）。最稳：同时用**不同形状**（实心/空心、圆/三角）编码数据。
4. **按钮/链接 vs 背景**：即使主色是绿（成功）或红（错误），也用**文字 + 图标**确认，且其与背景对比度 ≥ 3:1（非文本）或 ≥4.5:1（文字）。

### 5.3 WCAG 无障碍色板速查
- 设计一份**含图标/文字冗余 + 达到 AA**的状态色板，交付前用工具（如 Stark、Axe、WebAIM）跑一遍。
- 状态色同时给**文字标签**（"成功/失败/警告"），别让用户猜颜色含义。

## 六、可执行自检清单（写色板/页面时逐条过）

- [ ] 正文文字与背景对比度 ≥ 4.5:1？大标题 ≥ 3:1？
- [ ] 图标、按钮描边、控件边界 ≥ 3:1？
- [ ] 每种语义都有"颜色 + 文字/图标"双重编码？
- [ ] 没有用红/绿作为"唯一区分"手段（图表/状态）？
- [ ] 配色类型明确：单色 / 类比 / 互补 / 三角 / 分裂互补 / 中性加强调？主次面积是否分清？
- [ ] 中性底 + 单强调色是否足够表达层级？（现代产品默认）
- [ ] 心理学倾向是否被当作"参考"而非"定论"？

---

> **固化记忆点**：色彩三要素 **H（色相）/ S（饱和度）/ B（明度）**；创作用 **HSB**、交付用 **RGB/HEX**；排版核心硬标准 **正文字 4.5:1、大标题 3:1、非文本 3:1**；**永远用"颜色 + 文字/图标"双重编码**；默认配色走 **中性 + 单强调**。
