# L1 参考解剖 · Apple（消费科技 / 电商零售金标准）

> 来源：open-design/design-systems/apple（DESIGN.md + design-tokens.json + tokens.css）
> 用途：任何**消费电子 / 品牌电商 / 产品展示 + 在线订购配置器 / 灰白银高端品牌**的设计基准。
> 状态：✅ 范例确认（颜色以 design-tokens.json 实测为准；DESIGN.md 叙述中的非 token 颜色一律标注 ⚠️）

---

## 一、核心原则（先记这 8 条）

1. **中性三原色是结构地基**：白 `#ffffff`（bg）+ 浅灰 `#f5f5f7`（surface）+ 近黑墨 `#1d1d1f`（fg）。Apple 是**浅底白签**系统——token 层只定义浅色画布，绝不让 UI chrome 抢戏
2. **双档节奏：展示场（showcase）vs 交易场（commerce）**：同一套 token 下跑两种密度——营销页走「大章节、宽留白、黑底沉浸」的电影感；零售 / 订购页走「紧间距、多控件、密卡片堆叠」的交易效率。**不是两套设计系统，是一套系统的两档**
3. **唯一彩色 = 苹果蓝**：accent `#0071e3`（主动作底 / 焦点信号 / 品牌标记）是**全系统唯一彩色**，只留给真实动作与导航语义；其余全是灰阶
4. **产品图是情感承载者**：硬件、材质、饰面（finish）是叙事主角，UI chrome 刻意做薄——界面要「消失」，让产品成为前景
5. **双字体分工**：SF Pro Display 扛 hero / 商品大标题（紧凑行高 + 受控字距）；SF Pro Text 扛导航 / 控件 / 标签 / 密集交易文案
6. **胶囊 / 圆形是签名动作语言**：从 `8px` 标准控件到 `980px` 极限胶囊（`--radius-pill`），加圆形媒体/选择控件（50%）——苹果式「柔和但精准」的 CTA 剪影
7. **深度克制：用层级 + 边框，不用阴影堆**：深刻度靠「重语义（fg→fg-2→muted→meta）分层 + 表面跳变（白→浅灰→石墨）」；阴影（elev-raised `rgba(0,0,0,0.08)`）只作轻抬升辅助，不是深度的主角
8. **克制冷艳 = 灰白银**：灰阶偏「银/冷」（`#424245`、`#86868b`、`#6e6e73`），不出现暖橙色 / 暖黄交互；名牌冷淡、科技感、留白主导

## 二、颜色令牌（以 design-tokens.json 为准，可直接照抄）

| Token | 值 | 用途 |
|:--|:--|:--|
| bg | `#ffffff` | 页面 / canvas 背景（零售 / 产品列表 / 密集交易面） |
| surface | `#f5f5f7` | 主浅色面 / feature band / 对比块 / 编辑过渡 |
| surface-warm | `#fbfbfd` | 暖白表面（更柔和的白，品牌留白底色） |
| fg | `#1d1d1f` | 主文本 / 暗色填充控件底（浅底上的近黑墨） |
| fg-2 | `#424245` | 次级深灰文本 / 深灰工具表面（store 语境） |
| muted | `#6e6e73` | 次级说明 / 辅助描述 / 三级元数据 |
| meta | `#86868b` | 更弱的元数据 + 中强输入描边（一值双用） |
| border | `#d2d2d7` | 默认边框 / 分隔 / 轻微部件包含（软边灰） |
| border-soft | `#e8e8ed` | 更浅微边框（最弱分隔 / 细描边） |
| accent | `#0071e3` | 主动作底 / 焦点信号 / 品牌标记（**唯一彩色**） |
| accent-on | `#ffffff` | accent 上的文字 |
| accent-hover | `#0077ed` | accent 元素 hover（更亮蓝） |
| accent-active | `#0066cc` | accent 按下态 + 正文内联链接蓝 |
| success | `#16a34a` | 成功状态 |
| warn | `#eab308` | 警告 |
| danger | `#dc2626` | 危险 / 删除 |

**⚠️ 冲突 / 非 token 颜色（只在 DESIGN.md 叙述层，不在 tokens，谨慎使用）**：
- `#000000` 绝对黑——DESIGN.md 用作沉浸式 hero / 暗章节 / 深 UI 锚点，**token 集未定义**（token 只有浅色 bg=白）。仅在「营销黑章节」这一叙事层出现，**零售 / 订购面不动它**
- 石墨暗面 `#272729` / `#262629` / `#28282b` / `#2a2a2c`（暗卡片 / 媒体控制 / 暗工具簇）——**不在 token**，属暗语境专用 ⚠️
- 高亮链接蓝 `#2997ff`（暗场景上需要强对比的链接）——**不在 token** ⚠️
- DESIGN.md 表面集称「未见语义色」——但 token **明确定义了** success / warn / danger，**以 token 为准**（DESIGN.md 的「无语义色」只反映它抽取的那批营销表面，不代表系统无此令牌）⚠️

**阴影 / 焦点（辅助，非深度主体）**：elev-flat `none`；elev-ring `0 0 0 1px var(--border)`（边框当阴影）；elev-raised `0 12px 32px rgba(0,0,0,0.08)`；focus-ring `0 0 0 4px color-mix(in oklab, var(--accent), transparent 65%)`。

## 三、排版（SF Pro Display / SF Pro Text，无 OpenType 签名）

字体栈：`--font-display: "SF Pro Display", "SF Pro Icons", "Helvetica Neue", Helvetica, Arial, sans-serif`
`--font-body: "SF Pro Text", "SF Pro Icons", "Helvetica Neue", Helvetica, Arial, sans-serif`
`--font-mono: "SF Mono", ui-monospace, "JetBrains Mono", Menlo, Monaco, Consolas, monospace`
**分工**：Display 只扛 hero / 商品 / 区块大标题；Text 扛导航、控件、标签、密集电商文案。**主语料字重 600**（强调主体）；700 选择性出现；300 仅在大字号内做对比弱化。

| Token | 字号 | 行高 | 字距 | 用途 |
|:--|:--|:--|:--|:--|
| text-4xl | 80px | 1.05–1.07 | -0.015em | hero XL（environment / store hero） |
| text-3xl | 56px | 1.07 | -0.015em | hero L / 首页主 moment |
| text-2xl | 40px | 1.10 | -0.015em | 产品 / campaign 区块标题 |
| text-xl | 28px | 1.14 | +0.007em | 卡片 / 产品标题 / 关键文案 |
| text-lg | 21px | 1.14–1.38 | +0.008em | 大促销链接 / 动作标题 |
| text-base | 17px | 1.47 | -0.013em | 标准正文 / 零售描述（**正文基准字号 17px**） |
| text-sm | 14px | 1.29–1.47 | -0.008em | 按钮 / 助手标签 / 紧凑导航 |
| text-xs | 12px | 1.00–1.33 | -0.004em | 微标签 / fine print |

- **全局 token**：`--leading-body: 1.47`、`--leading-tight: 1.05`、`--tracking-display: -0.015em`（Display 用负字距，正文放松）
- Apple 用**实测 px**（80/56/40/28/21/17/14/12），无 Linear 式 `display-lg/heading-1` 命名——按 token 直取即可。
- **⚠️ DESIGN.md 层级是 token 的超集**：比 token 多了 `48 / 38 / 32 / 24 / 19 / 10px` 中间档（如 Section Display 48、Feature Display 38、Promo 32、Utility Heading 24、Subhead 19、Legal 10）——需要更细粒度时用 DESIGN.md 的，但**语义字号以上表 token 为准**（17px 正文 / 12px 微标签是硬基准）。
- **字重阶梯**：600 是主导强调；文案正文 400；300 只在大字号里做明暗对比。
- **替代字体**（无 Apple 字体授权时）：`Inter` 替 Text、`Inter Tight` 替 Display 度量。替代时正文行高压 +0.02~0.06、负字距减弱，以保可读性。

## 四、组件样式（按钮 / 卡片 / 输入 / 导航）

### 按钮
- **Primary Fill（主动作）**：底 `#0071e3`（accent），字 `#ffffff`，圆角 8，紧凑横 padding（常见 8px 15px）——决定性购买 / 推进动作
- **Dark Fill（浅底上的克制主按钮）**：底 `#1d1d1f`（fg），字 `#ffffff`，圆角 8——浅面需要高对比但不喧宾夺主的首选
- **Pill / 胶囊家族**：大胶囊动作 `18px–56px` 圆角、极限胶囊链接 `980px`（`--radius-pill`）——苹果式柔和精准 CTA 剪影
- **Utility Filter / 工具壳**：浅壳（`#fafafc` 或半透白）+ 灰边框（`#d2d2d7` / `#86868b`）——密集配置语境
- **按下行为**：active 常伴随「轻微缩小 / 填充转暗」还原物理按压；focus-ring 用 `color-mix(accent, transparent 65%)` 的 4px 光环

### 卡片 / 容器
- **编辑 / 产品卡**：`#f5f5f7` 或白字段上的浅卡，极简边框、图像优先构图
- **暗工具卡**：石墨跳变（`#272729`→`#2a2a2c`，⚠️ 非 token）用于 overlay / 媒体控制 / 暗语境模块
- **配置器面板**：`12px–18px` 圆角（对应 `--radius-md` `--radius-lg`），清晰而克制的边界定界
- **Carousel / Spotlight 模块**：`28px–36px` 大圆角壳（featured 内容泳道）
- **边框圆角档**（token）：`--radius-sm 8 / --radius-md 12 / --radius-lg 18 / --radius-pill 980`；⚠️ DESIGN.md 叙述另含 `5 / 16-18 / 28-36 / 56 / 100 / 50%` 中间档——**按组件类别分档（字段 / 卡片 / 胶囊 / 圆形），不要一刀切统一圆角**

### 输入 / 表单
- **零售输入字段**：半透明白或白底 + 深字 `#1d1d1f`，边框主导包含（`#86868b` / `#d2d2d7`）
- **选择控件**：圆形 / toggle 式几何在选品界面高频出现
- **密度策略**：表单保持视觉安静，让产品图与定价层级保持主导

### 导航（克制冷艳铁律）
- **全局营销导航**：紧凑暗半透条 + 小字号链接 + 克制的图标
- **Store / 子店导航层**：额外工具条 / chips / 分段控件，用于品类与产品收窄（密集化）
- **链接层级**：链接蓝（`#0071e3` 动作 / `#0066cc` 正文链接）是主要交互信号；灰阶只承载密集导航

### 图像处理
- **对象优先摄影**：硬件 / 配件置于受控纯色面上（悬浮感）
- **高保真饰面渲染**：反光 / 材质细节是视觉说服的核心
- **混合构图**：全出血 hero 场景 ↔ 圆角零售卡 ↔ 紧裁商品缩略图并存

### 其它标志性组件
- **产品配置矩阵**：chips + radio 式选择器 + 情境定价 / 汇总块的选项叠层
- **Carousel 控制点 / 箭头**：圆形控制词汇 + 柔和 overlay（圆形 50%）
- **Environment 叙事章节**：编辑排版 × 电影级产品 / 环境示意图融合

## 五、布局原则（大留白 + 双档密度）

- **间距 token**：`--space-1 4 / -2 8 / -3 12 / -4 16 / -5 20 / -6 24 / -8 32 / -12 48`（**基元 8px**，支持微步精准对齐）
- **章节纵距**：`--section-y-desktop 100px / -tablet 64px / -phone 40px`（展示场用大章节留白，交易场按需压缩）
- **容器**：`--container-max 1024px`；gutter `desktop 22 / tablet 18 / phone 16px`；桌面端受限可读核心 + 外侧宽松留白
- **网格**：展示页走「大中央列 + 全彩章节」；交易页走「紧多列产品 / 控件网格 + 频繁模块堆叠」
- **留白哲学**：**对照式分隔**——章节过渡靠「表面跳变」（白↔浅灰↔黑）而非装饰分隔线；展示场大留白，交易场刻意压缩以堆信息
- **⚠️ DESIGN.md 叙述额外提及**高频间距 `2/6/7/9/10/14/17px`——token 只到 4/8/12/16/20/24/32/48，需更细台阶时按需补，但**8px 基元 + 14-20px 实用间隔是主骨架**

## 六、深度与层级（克制，层级 + 边框主）

| Level | 处理 | 用途 |
|:--|:--|:--|
| Level 0 | 平面中性面（`#ffffff`、`#f5f5f7`、`#000000`⚠️） | 主叙事 / 产品舞台 |
| Level 1 | 轻微边框包含（`#d2d2d7`、`#86868b`） | 过滤 / 输入字段 / 工具卡 |
| Level 2 | 柔和阴影（`rgba(0,0,0,0.08)`；elev-raised `0 12px 32px`） | 高亮卡 / 抬升商品模块 |
| Level 3 | 暗面跳变（`#272729`→`#2a2a2c`⚠️） | overlay / 媒体控制 / 暗工具簇 |
| Accessibility | 蓝焦点信号（accent `#0071e3`，4px 光环） | 键盘 / 选择强调 |

深度刻意克制：Apple 靠**色调对比 + 表面跳变 + 构图层级**，不靠重阴影堆栈。装饰性深度用**摄影真实感 + 材质渲染**制造，而非合成 UI 效果；半透 overlay / 玻璃感工具条只提供轻微氛围分层。

## 七、Do's and Don'ts（Apple 的「别这样做」）

**Do：**
- 用中性三原色（`#ffffff`、`#f5f5f7`、`#1d1d1f`）当结构地基，`#000000` 留给营销黑章节（⚠️ 非 token）
- 蓝 accent 只留给真实动作与导航语义；**蓝用于真正的事，全蓝会崩掉层级**
- 排版尤其在大字距处保持紧与克制（Display 带负字距）
- 维持胶囊 / 圆形几何做控件与关键动作
- 让产品图承载视觉戏剧性，chrome 保持低调
- 密集零售语境用「边框主导包含」而非厚重卡片装饰
- 在展示场与交易场间保持清晰分隔，但共享同一套核心 token（一套系统两档）

**Don't：**
- 别引入与苹果蓝竞争的次强调彩色（仅 accent 一条彩色，成功 / 警告 / 危险只做指示）
- 别在核心 UI chrome 过度用阴影、glow、装饰性渐变（token 层是实色面驱动）
- 别混用无关字体族，也别随意放开字距
- 别把所有圆角压成单一值——Apple 用有目的的圆角档位（8/12/18/980 + 50%）
- 别用厚边框或喧闹视觉拱坏交易模块
- 别移除暗 / 亮章节之间的中性对比节律
- **别把营销与购买流程当两套设计系统**（同一套 token，两种密度）

## 八、判断词

- ✅ 克制冷艳、灰白银、大留白、双档密度、唯一彩色蓝、图像主导、胶囊/圆形动作语言、边框+跳变分层、SF Pro Display 大标题负字距、高级科技感
- ❌ 多强调色、暖橙/暖黄交互、重型阴影/光晕/渐变、统一顺滑圆角、密集交易区加厚边框、把购买流程做出第二套系统、UI chrome 喧宾夺主

## 九、适用边界

**适用于**：消费电子品牌官网 / 电商、产品展示页、在线订购与配置器（buy flow）、高端灰白银品牌落地页、营销 + 交易混合的零售语境、画廊式产品叙事。

**不适用于**：暗色 SaaS 运营后台 / 开发者工具（那用 Linear——见 `reference-linear.md`）、超明亮营销落地页的「活力友好」风（那按需参考 Strip/vercel）、暖色人文品牌（那用 Claude）、需要「多彩灵动 / 游戏感 / 渐变炫技」的界面。

---

### 备注：与 Linear（暗色参考）的对照锚点
- **Apple = 浅色 / 消费 / 图像主导 / 双档密度**；**Linear = 暗色 / B 端工具 / 信息密度 / 白透明度梯级**。
- 若你要做「消费类但偏工具感」，以 Linear 的工程感密度为骨、Apple 的克制蓝灰为皮——但**底色体系二选一**，不要混（一个是浅底浅灰白，一个是暗底白透明度），混了会失去各自身份。
