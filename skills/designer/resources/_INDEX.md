## 使用流程（做项目前必做）

1. **判断场景** → 上面 A~H 哪一桶
2. **加载代表** → 读对应桶✅已蒸馏的知识文件
3. **需要更细** → 读对应桶备选模板全文
4. **确认风格** → 用 `browser_vision` 截真实参考站对比
5. **蒸馏落地** → 按项目 DESIGN.md 写自己的 token/组件
